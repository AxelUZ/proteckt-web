# Proteckt Website

Landing page oficial de Proteckt, empresa especializada en control profesional de plagas en Mexicali, Baja California.

## Tecnologías

- React
- TypeScript
- Vite
- Tailwind CSS v4
- ESLint
- Prettier

## Instalación

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```
